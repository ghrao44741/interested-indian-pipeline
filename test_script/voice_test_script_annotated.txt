VOICE-CLONING RECORDING SCRIPT — ANNOTATED
==============================================
Same 189-word script as before (~70-100s at a natural pace). Read it out loud
exactly as marked below — the marks are pacing/emphasis guides, don't say them.

LEGEND
  /    = short pause (comma-length beat)
  //   = longer pause (let it land before continuing)
  CAPS = stress this word slightly (don't shout — just lean into it)
  [italics-style notes in brackets] = tone/delivery direction for that section

Overall: talk like you're explaining something absurd to a friend, not reading
the news. Confident, a little dry, not stiff.
==============================================

[Punchy, confident open — this is the hook]
Here's a number that should worry you: // one point three lakh. / That's how
many MBBS seats exist in the ENTIRE country, / for EVERY student who wants to
become a doctor.

[Matter-of-fact, then dry/ironic on the last line]
The National Testing Agency was created in November 2017 / with ONE job — //
run India's biggest exam / without breaking it. / Nine years later, //
NINETY-NINE percent of that promise / is still, technically, / a work in
progress.

[Quicken slightly through the questions — build a little energy, then land hard on "fair"]
So why does this keep happening? / Is it the exam? / Is it the agency? // Or
is it just that we've built a system / where twenty-two point SEVEN lakh
people / compete for one point THREE lakh seats, / and called that FAIR?

[Slow down here — more grounded, human, storytelling tone]
Whole towns exist / because of this math. // Kota, in Rajasthan, / is
basically one giant coaching economy — / parents relocate their teenagers /
for a year, sometimes two, / betting a serious chunk of household savings /
on ONE exam.

[Pick the energy back up — almost gleeful irony, like telling a great story at a party]
A judge once compared frustrated activists / to COCKROACHES. // Within
SEVENTY-EIGHT hours, / they'd turned it into a political party. / That's not
a footnote — // that's the whole country's sense of humor, / WEAPONIZED.

[Slow, wry, definitive close — let the last line breathe]
Whatever happens next, / one thing is certain: // the committee report / is
already being written. / It always is.
